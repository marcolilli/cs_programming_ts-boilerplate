# TypeScript Boilerplate

Short starter for running a single TypeScript entry point.

## Getting started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run the app (type-checks first):

   ```bash
   npm run start
   ```

## Scripts

- `npm run start` — Performs type-checking and runs the app.
- `npm run build` — Transpiles TypeScript to JavaScript and outputs to `dist/`.

**Note:** You can pass arguments to the script by appending them after `--`. For example:

```bash
npm run start -- arg1 arg2
```

## Project layout

- `src/index.ts` — Main entry point.
